# 🇺🇸 USA Family Trip 2027

2027년 미국 가족여행을 위한 개인 여행 계획 사이트입니다.

## 여행 기간

2027/01/30 ~ 2027/02/10

## 주요 여행 지역

- Los Angeles
- Las Vegas
- Grand Canyon
- San Diego

## 주요 기능

- 여행 일정
- 날짜별 교통 정보
- 지역별 호텔
- 미국 여행 가이드
- 여행 체크리스트
- 모바일 대응
- 로그인 불필요
- LocalStorage 체크리스트 저장

## 미국 여행 가이드

Visit The USA의 공식 한국어 자료를 참고하여
미국 여행에 필요한 정보를 한국어로 정리합니다.

공식 사이트:

https://www.visittheusa.com/ko/

## GitHub 사용 방법

1. GitHub 저장소를 엽니다.
2. 위 파일들을 업로드합니다.
3. api 폴더도 그대로 업로드합니다.
4. Commit changes를 누릅니다.
